## 1. Rocket Lab (RKLB)

### 一、生意本质 — 段永平"对的生意"

**一句话定义**：Rocket Lab 是全球唯二具备可靠商业发射能力的民营航天公司（仅次于SpaceX），正在从"小型火箭发射商"向"端到端太空系统公司"进化。

**核心数据（估测，基于公开信息）**：
| 指标 | 数值 |
|------|------|
| 当前股价 | ~$70（从YTD高点$175回撤60%） |
| 预估市值 | ~$350亿 |
| FY2025收入 | ~$4.5-5亿 |
| 积压订单(Backlog) | **超过$10亿**（历史新高） |
| Neutron火箭 | 预计2026年首发 |
| 发射频次 | 已完成50+次Electron发射 |

**收入结构**：
- 发射服务（Electron火箭）：约40%
- 太空系统（卫星组件+制造）：约60%
- 未来增长引擎：Neutron中型火箭（对标Falcon 9）+ 太空服务

**段永平式追问**：SpaceX估值~$3500亿，Rocket Lab能否达到其1/5甚至1/3？如果Neutron成功，客户需要"第二供应商"，因为没人愿意被SpaceX完全锁定。

**反面论据**：Neutron首发延期风险、SpaceX价格战、发射失败风险、太空经济整体还处于早期。

### 二、护城河评估 — 巴菲特"经济护城河"

| 护城河类型 | 评级 | 分析 |
|-----------|------|------|
| 技术/专利壁垒 | ★★★★ | 火箭发动机技术+发射工艺，极高壁垒 |
| 转换成本 | ★★★★★ | 一旦客户将卫星集成到Rocket Lab平台，切换成本极高 |
| 规模效应 | ★★★ | 年发射次数增加→单位成本下降 |
| 品牌/定价权 | ★★★ | 可靠性记录是定价权来源 |
| 网络效应 | ★★ | 不适用 |

**护城河趋势**：**变宽中**。Neutron如果首发成功，将从"小型火箭"升级到"中型火箭"，可触及市场扩大10倍。

**巴菲特式追问**：10年后SpaceX和Rocket Lab还能共存吗？答案：能。因为政府客户强制要求"双供应商"，商业客户也需要议价权。这就好比波音和空客的关系。

### 三、逆向思考与风险清单 — 芒格"反过来想"

| 失败路径 | 概率 | 影响 | 
|---------|------|------|
| Neutron首发失败，公司信誉和股价腰斩 | 15-20% | 极高 |
| SpaceX发起价格战，压缩利润率 | 30-40% | 高 |
| 太空经济热度消退，估值下杀 | 25% | 高 |
| 现金流耗尽，需要稀释融资 | 20% | 中 |
| 关键人才被SpaceX/Blue Origin挖走 | 10% | 中 |

**芒格式追问**：聪明人为什么不做多RKLB？——"它还在亏钱，估值远超当期收入，Neutron还不能飞"。这些是事实，但如果等一切都确定了，股价也不会有10倍空间了。

### 四、管理层 — "对的人"

- CEO Peter Beck：新西兰人，自学成才的火箭工程师，持股比例高，把火箭发射从"神圣科学"变成了"工程问题"
- 关键决策：从Electron到Neutron的战略延伸、垂直整合（不依赖外部供应商）
- 资本配置：谨慎，优先投入研发

### 五、文明趋势 — 李录"文明演进框架"

太空经济正在从"政府主导"向"商业主导"转变。Rocket Lab站在两条文明级趋势的交汇处：
1. **太空商业化**：SpaceX证明了这条路，Rocket Lab是唯二的受益者
2. **太空国防化**：美国国防部对太空资产的依赖越来越深

李录式追问：站在2040年回看，Rocket Lab是"这个时代的波音"还是"昙花一现的挑战者"？

### 六、估值与安全边际

| 情景 | 2031年预估收入 | 预估PE | 目标市值 | 潜在回报 |
|------|-------------|--------|---------|---------|
| 乐观（Neutron大获成功） | $80-100亿 | 15-20x | $1200-2000亿 | **3-6倍** |
| 中性（稳步增长） | $40-50亿 | 12-15x | $500-750亿 | **1.5-2倍** |
| 悲观 | $15-20亿 | 8-10x | $120-200亿 | **-50%** |

**关键判断**：RKLB要实现10倍（$3500亿市值），需要在2031年达到$150-200亿收入。这要求Neutron完全成功+太空系统业务大爆发+全球发射市场持续增长。**不是不可能，但需要一切顺利。**

**结论**：★★★ 优质公司，3-5倍确定性较高，10倍需要多因素共振。

## 2. IonQ (IONQ)

### 一、生意本质

**一句话定义**：IonQ是全球唯一有商业收入的纯量子计算上市公司，基于离子阱技术路线，正在从"科研玩具"向"商业计算工具"过渡。

**核心数据**：
| 指标 | 数值 |
|------|------|
| 当前股价 | ~$33 |
| 预估市值 | ~$100亿 |
| FY2025收入 | ~$4300万（增速~100%+） |
| 预订(Bookings) | 快速增长 |
| 技术路线 | 离子阱（与超导、光量子并列三大路线） |
| 量子比特数 | 已实现~64算法量子比特 |

**收入结构**：几乎全部来自量子计算云服务接入+少量硬件销售。

**段永平式追问**：这门生意好在哪？——量子计算是计算范式的根本改变。一旦达到"量子优势"，IonQ将处于一个万亿级市场的前沿。

**反面论据**：FY2025收入仅$4300万，估值$100亿意味着PS~200倍。量子计算的"ChatGPT时刻"还没有到来，可能还需要3-5年甚至更久。

### 二、护城河评估

| 护城河类型 | 评级 | 分析 |
|-----------|------|------|
| 技术/专利壁垒 | ★★★★★ | 量子计算专利+离子阱工艺，极高壁垒 |
| 转换成本 | ★★★★ | 一旦在IonQ平台上开发算法，迁移成本高 |
| 先发优势 | ★★★★ | 唯一有收入的纯量子公司 |
| 品牌 | ★★ | 量子计算品牌认知度仍低 |
| 网络效应 | ★ | 暂不适用 |

**巴菲特式追问**：如果Google/IBM/MSFT突然在量子计算上取得重大突破，IonQ的护城河还在吗？——这是最大的风险。科技巨头有几乎无限的资源。

### 三、逆向思考

| 失败路径 | 概率 | 影响 |
|---------|------|------|
| 超导量子路线率先突破，离子阱路线被证明不是最优 | 30-35% | 致命 |
| 量子计算商业化时间远超预期（>10年） | 25% | 致命 |
| 大公司（Google/IBM）推出免费量子云服务 | 30% | 高 |
| 每年烧钱$2-3亿，需要持续融资稀释 | 40% | 中 |

### 四、文明趋势 — 李录

量子计算如果实现突破，将是自晶体管发明以来最大的计算范式变革。这不是一个"行业投资"，而是一个"文明级别的押注"。

### 五、估值

| 情景 | 2031年预估收入 | 目标市值 | 潜在回报 |
|------|-------------|---------|---------|
| 乐观（量子优势实现） | $50-100亿 | $1500-3000亿 | **15-30倍** |
| 中性 | $10-20亿 | $300-600亿 | **3-6倍** |
| 悲观（路线失败） | ~$0 | ~$0 | **-100%** |

**结论**：★★★ 量子计算的纯赌注，10倍潜力存在但风险极高。适合在组合中配置1-2%。

## 3. AST SpaceMobile (ASTS)

### 一、生意本质

**一句话定义**：AST SpaceMobile正在建设全球第一个"直接连接普通手机"的卫星宽带网络——你不需要特殊手机，不需要换SIM卡，在沙漠/海洋/飞机上也能用4G/5G。

**核心数据**：
| 指标 | 数值 |
|------|------|
| 预估市值 | ~$250亿（近期因AT&T合作暴涨，增加了~$100亿市值） |
| 收入 | 尚未产生商业收入（预商用阶段） |
| 合作伙伴 | AT&T、Vodafone等全球顶级运营商 |
| 卫星数量 | 首批5颗BlueBird卫星在轨测试 |

**段永平式追问**：客户为什么需要这个？——因为地球表面90%没有手机信号。运营商愿意付钱吗？AT&T已经签约了，这是最好的证明。

### 二、护城河

- 技术壁垒极高：超大相控阵天线（~64平方米），在近地轨道展开，技术复杂度远高于Starlink
- 先发优势：5颗卫星已经上天并在测试
- 频谱权利：FCC授权

**巴菲特式追问**：Starlink/T-Mobile为什么不直接做？他们也在做，但ASTS的专利和天线设计领先2-3年。

### 三、核心风险

- **最大风险**：技术能否大规模商业化（20颗+卫星组网）还是未知
- **烧钱**：需要大量现金（最近又融资一轮）
- **竞争**：SpaceX Starlink Direct to Cell正在追

### 四、估值

TSR（完全组网成功）= $500-1000亿 → **2-4倍**；5年实现$100亿收入 → $1500亿+ → **6-10倍**

**结论**：★★★ 最具想象力的美股之一，但还在"证明自己"的阶段。

## 4. Oklo (OKLO)

### 一、生意本质

**一句话定义**：Oklo是新一代核能公司，发展小型快中子反应堆(SFR)，专为AI数据中心提供零碳、稳定、不受天气影响的电力。

**核心数据**：
| 指标 | 数值 |
|------|------|
| 预估市值 | ~$120亿 |
| 收入 | 0（预营收阶段） |
| 设计审批 | NRC（美国核管会）审查中 |
| 合作方 | 已与多个数据中心运营方签订意向 |

**段永平式追问**：这门生意好在哪？——AI数据中心每年耗电增长50-100%，电网无法满足需求。核电是唯一可24/7零碳运行的解决方案。

### 二、护城河

- **NRC审批壁垒**：美国核电审批极为复杂漫长，先获批者享受巨大的先发优势
- **技术路线差异**：Oklo的快堆设计燃料利用率远高于传统核电站

### 三、核心风险

- NRC审批失败/延期
- 核电公众接受度
- 第一座商用反应堆成本可能远超预期

### 四、估值

到2031年如果成功部署5-10座反应堆，收入可达$50-100亿，对应市值$500-1500亿 → **5-12倍**

**结论**：★★★ 核电是AI基础设施最大的瓶颈之一，Oklo是最有希望解决这个问题的公司。

## 5. Reddit (RDDT)

### 一、生意本质

**一句话定义**：Reddit是全世界最大的人类对话数据库——20年来积累了数十亿条真实人类对话，在AI时代，这些数据就是新的石油。

**核心数据**：
| 指标 | 数值 |
|------|------|
| 预估市值 | ~$300-400亿 |
| FY2025收入 | ~$13亿（增速40%+） |
| 日活用户 | ~1亿 |
| AI数据授权 | Google/OpenAI均已签约 |
| DAU增长 | 持续双位数增长 |

**段永平式追问**：这生意好在哪？——网络效应极强（用户越多→内容越多→搜索越有用→更多用户），AI数据授权是新的变现方式。

**反面论据**：广告收入对经济周期敏感，AI数据授权的持续性存疑（大模型训练完成后还需要Reddit数据吗？）

### 二、护城河

| 护城河 | 评级 | 分析 |
|-------|------|------|
| 网络效应 | ★★★★★ | 本质上不可复制——20年的对话历史 |
| 数据壁垒 | ★★★★★ | AI训练数据的黄金标准 |
| 转换成本 | ★★★★ | 用户社区的沉没成本 |

### 三、估值

5年后达到$100-150亿收入（广告+数据授权），20-25x PS → $2000-3750亿 → **5-10倍**

**结论**：★★★★ 10家公司中确定性最高的一家，10倍潜力取决于AI数据授权能否成为第三增长曲线。

**段永平式追问**：为什么2025年拐点来了？——人形机器人产业从"概念验证"进入"量产准备"阶段。特斯拉Optimus、小米CyberOne、宇树科技等都需要谐波减速器。

**反面论据**：PE接近400倍极贵，如果人形机器人量产进度不及预期，估值可能腰斩再腰斩。

### 二、护城河评估 — 巴菲特

| 护城河 | 评级 | 分析 |
|-------|------|------|

| 规模效应 | ★★★ | 产量越大单位成本越低 |
| 品牌 | ★★★ | 国内谐波减速器第一品牌 |

**竞争对手**：日本Harmonic Drive（全球龙头）、来福谐波、大族精密等。绿的谐波是国内唯一能批量交付高端谐波减速器的厂商。

**巴菲特式追问**：如果人形机器人真的爆发，Harmonic Drive会不会扩产打击绿的谐波？有可能，但中国市场客户更偏好国内供应链（政策+成本+响应速度）。

### 三、逆向思考 — 芒格

| 失败路径 | 概率 | 影响 |
|---------|------|------|
| 人形机器人产业化进度不及预期 | 30% | 极高-致命 |
| 国产替代后被替代（后来者追上） | 20% | 高 |

| 产能扩张过快导致利用率不足 | 25% | 中 |

### 四、文明趋势 — 李录

**人形机器人是"文明级"的变革**——从工业文明进入"具身智能文明"。如果2035年全球人形机器人年出货达到100万台，每个用20个谐波减速器，就是2000万个/年的需求。绿的谐波如果占30%份额，营收可达数十亿甚至上百亿级别。

李录式追问：站在20年后回看，绿的谐波是"机器人时代的标准石油"还是"通用汽车之前的某个小零件商"？
